OVERVIEW

Simple to use and highly customizable grass spawner for most terrains. Generate hundreds of thousands of grass blades using the textures of your choice at the click of a button.

INSTALLATION

standard unity package installation https://docs.unity3d.com/Manual/upm-ui-install.html

FEATURES:

    Add up to 4 different grass textures to populate terrain
    Select the individual density of each grass type
    Control height limits for where grass is allowed to spawn
    Control the size of grass blades for each grass type
    Control the ways in which wind will affect grass

HOW TO USE:

    Add Mesh Collider Terrain Sampler to your terrain object
    Add your terrain's collider to "Terrain collider" variable slot
    Add Grass Spawner prefab to your scene as a child of your terrain
    Reset position of Grass Spawner Object
    Add your terrain's mesh collider terrain sampler to terrain sampler variable slot on the Grass Spawner Script.
    Edit grass parameters according to your needs
    Click "Generate" button
