# Decoration Guide

## Grapple Crystals
- All grapple crystals can be found within `Prefabs/GrappleCrystals`
- The player is only able to grapple onto these crystals, so use them for your puzzles!
- Feel free to scale and rotate them however you see fit/

## Terrain
- To create terrain, you should use the `Main Terrain.asset` file.
- This terrain set contains:
  - 6 surface types
  - 4 tree types
  - 11 detail types, including rocks, foliage and fungi

## Rocks
- Rocks of many different shapes and sizes can be found in the `Rocks` folder.
- None of these prefabs come with colliders, but can be easily added by adding a `Mesh Collider` to any prefab you want to use.

## Bridges
- `EmaceArt/Roadside Tales Bridges/Prefabs` contains over a dozen different wooden bridge variations.
- All of these come with colliders.

## Misc Assets
- Bird flocks (`MaekoFlock`)
- Skog VFX ('Skog/Particles`)
  - Falling maple leaves
  - Fireflies
